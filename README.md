# Distrito Palmerola — Sitio web

Borrador conceptual del sitio web para el proyecto **Distrito Palmerola**, un desarrollo de **CIMA PROPERTIES**: el primer distrito de usos mixtos junto al Aeropuerto Internacional de Palmerola (Comayagua, Honduras).

Propuesta y desarrollo por **HonduWeb** — [www.honduweb.net](https://www.honduweb.net)

## Contenido
- `index.html` — landing conceptual (tema claro, tipografía Fraunces + IBM Plex Mono, acento teal).
- `cotizacion.html` — propuesta técnica y económica (versión web).
- `assets/` — estilos, JavaScript e iconos SVG.

## Estado
Borrador de diseño. Pendiente: renders oficiales, datos de contacto reales y la fase de plataforma autoadministrable (Laravel + MySQL).

## Fase 2 — Plataforma autoadministrable
Panel de administración para gestionar contenido, subir proyectos, cambiar logo e imágenes, editar textos y datos, sin tocar código. Backend **Laravel**, base de datos **MySQL**.
